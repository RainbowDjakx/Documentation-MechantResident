
Pour le combat à distance les joueurs disposent d’un panel d’armes. 

Pour tirer sur un monstre, il est nécessaire de le Verrouiller Lorsqu’un monstre est Verrouiller il est possible de choisir entre trois cibles : les jambes, la tête et le torse. 

Un personnage peu Verrouiller un mutant que s’il est dans les 60° devant lui.

Il est possible de passer son lock d’un monstre à l’autre.

---

Infliger des dégâts : 

- Si le joueur tire sur le monstre il inflige les dégâts de base de son arme
    
- Si le joueur tire sur un point faible du monstre les dégâts de l’arme sont doublés
    
- Si le joueur tire sur un point d’armure les dégâts de l’arme sont réduits
